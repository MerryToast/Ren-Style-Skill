# NOTICE — Third-party text

This repository contains **no full-text papers**. The public skill layer contains only:

1. Style rules and statistics distilled from the corpus (facts/rules, not expression).
2. Short excerpts from **open-access** papers, reused under their licenses with attribution (listed below).
3. Synthetic examples written in the target style with fictitious content.

Excerpts from publisher-copyrighted papers are kept **only** in the local, gitignored
`skills/ren-style-skill/examples.local/` directory and are never distributed.

The author (Prof. Wanbin Ren, HIT) has been informed of and agreed to this project.
